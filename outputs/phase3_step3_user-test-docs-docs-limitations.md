# Known limitations: Revision Rounds

- Single project active at a time; switching projects retains the previous one in localStorage but does not provide a project list or switcher.
- No multi-user collaboration, cloud sync, or client-facing portal.
- No email notifications or automated client communication.
- No analytics, tracking, or third-party scripts.
- No payments, subscriptions, or monetization features.
- Export is plain text only; PDF generation is not included.
- No user accounts, authentication, or backend — data lives only in the browser's localStorage.
- Data is lost if browser localStorage is cleared (or if the user clicks **Clear all data**).
- Tested in current Chrome, Firefox, Safari, and Edge only.
- Your data is saved only in this browser on this device (localStorage). It does not sync between devices, and clearing browser data deletes it: export regularly.
- Not included in this version: User accounts, authentication, or cloud sync
- Not included in this version: Payment processing, subscriptions, or any monetization
- Not included in this version: Multi-user collaboration or client-facing portal
- Not included in this version: Email notifications or automated client communication
- Not included in this version: Analytics, tracking, or third-party scripts
- Not included in this version: Template kit (markdown templates)
