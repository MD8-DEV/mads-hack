Who it is for

Solo freelance web and UI designers on fixed-price projects who need to track revision rounds against contracted limits. Not for agencies, teams, hourly-billing freelancers, or designers who need cloud sync across devices.

The outcome

Designer logs a client revision request, sees the round count update instantly against the contracted limit, and exports a client-ready summary showing rounds used, remaining, and the new request details — all before starting unpaid work.

What is available now

A localStorage-only static web tool (index.html) that runs entirely in the browser. You can: create projects with a contracted revision limit (1–100), log revision requests with descriptions, see current round vs. limit in real time, and export a text-file summary (project name, contracted rounds, rounds used, rounds remaining, revision list with timestamps). Data persists in your browser's localStorage. No account, no server, no payment. All 21 critical tests and 12 acceptance criteria pass. Known issues: revision limit >100 is accepted despite max="100" attribute; export filename may be malformed if project name has no alphanumeric characters.

Not included yet: Cloud backup or multi-device sync; PDF export (only .txt); client-facing portal or shareable links; notifications or reminders; integrations (Figma, Slack, email); team/workspace features; analytics or reporting across projects; any backend or database; payment processing (the store page is mocked).

Demo

1. Open index.html in a browser. 2. Enter a project name (e.g., "Meridian Dashboard Redesign") and contracted revision rounds (e.g., 3). Click "Create project". 3. Click "Log revision", enter a description (e.g., "Client wants sidebar navigation changed to top bar"), submit. Repeat for a second revision. 4. Observe the round counter update (2 of 3 used, 1 remaining). 5. Click "Export client-ready summary" — a .txt file downloads with the project details and both revisions listed. 6. Click "New project" to start another; previous project data remains in localStorage.
