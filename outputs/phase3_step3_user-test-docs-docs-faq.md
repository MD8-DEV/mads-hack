# FAQ: Revision Rounds

### Where is my data stored?

All data is stored in your browser's localStorage under the key `revision-rounds-project`. Nothing is sent to any server.

### How do I export the summary for a client?

Click **Export client-ready summary**. A plain-text file downloads with the project name, contracted rounds, rounds used, rounds remaining, and each logged request with timestamp.

### What happens if I clear my browser data?

Clearing browser data (including localStorage) will remove the saved project. The tool also has a **Clear all data** button that does the same with a confirmation prompt.

### Can I work on multiple projects at the same time?

Only one project is active at a time. Clicking **New project** saves the current project in localStorage and lets you start a fresh one. The previous project's data remains in localStorage but is not accessible until you clear the current project and re-enter its details.

### Does the tool send me email notifications or notify the client?

No. The tool has no backend, no email, and no automated communication. You manually share the exported summary file with the client.

### Can I generate a PDF instead of a text file?

Export is plain text only. PDF generation would require an external library, which is excluded to keep the file self-contained and under 200 KB.

### Is there a cloud sync or account login?

No accounts, login, or cloud sync. The tool works entirely offline after the initial page load.

### What browsers are supported?

Current versions of Chrome, Firefox, Safari, and Edge.
